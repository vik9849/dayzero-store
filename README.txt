DAYZERO STOREFRONT — STARTER BUILD

WHAT THIS IS
A responsive static storefront concept with:
- Premium editorial homepage
- 8 sample product cards and category filters
- Working browser-side shopping bag (localStorage)
- Mobile layout
- Newsletter interaction placeholder

IMPORTANT — NOT READY TO ACCEPT REAL ORDERS
The displayed products are design mockups, not connected Printful catalog items.
Prices are illustrative, not verified against fulfilment costs.
Checkout is intentionally not connected. Do not advertise or accept payment until:
1. Each product is created in Printful and product variants, costs, shipping and delivery estimates are confirmed.
2. Product images are replaced with actual Printful mockups.
3. A compliant checkout is connected and tested end-to-end.
4. Contact, privacy, refund, shipping and terms pages are completed.
5. Tax, business and platform requirements are checked.

DEPLOY ON GITHUB PAGES
1. Sign in to GitHub.
2. Create a NEW PUBLIC repository named dayzero-store.
3. Upload index.html, styles.css, app.js and README.txt to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish. Your site URL will appear in Settings > Pages.

TO CUSTOMIZE
- Product names, categories and sample prices are in app.js.
- Styling is in styles.css.
- Main page sections are in index.html.
